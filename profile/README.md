# Siphonophore

## What is Siphonophore?

Siphonophore is a collection of purpose-built plugins that extend Jellyfin administration. Each plugin runs entirely inside Jellyfin with no external applications or dependencies to install, host or keep running beside it. The aim of these plugins is to make common administrative tasks more user friendly and lower the barrier to entry for new Jellyfin users.

## Why Siphonophore?

A [siphonophore](https://en.wikipedia.org/wiki/Siphonophore) is a colony of small animals that lives and moves as one. Each member is a [zooid](https://en.wikipedia.org/wiki/Zooid) with a single job. The [nectophores](https://en.wikipedia.org/wiki/Nectophore) are the swimming bells that move the colony, and every member grows from the [stolon](https://en.wikipedia.org/wiki/Stolon), the stem that joins them all. 

The most common example is a [Portuguese Man O' War](https://en.wikipedia.org/wiki/Portuguese_man_o%27_war) which resembles a Jellyfish but is actually a series of interconnected, unique organisms working together. The idea of these plugins is to act similarly, where Jellyfin is the core and all these plugins depend on, and extend, Jellyfin into a more robust *colony*. The goal is to handle Jellyfin adjacent functionality directly rather than requiring users utilize a different external program for each task.

## Installing

Add this repository in Jellyfin under **Dashboard > Plugins > Repositories**:

```
https://repo.siphonophore.org
```

See [siphonophore](https://github.com/siphonophore-org/siphonophore) for the unstable channel and the full steps.
