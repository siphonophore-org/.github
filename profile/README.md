# Siphonophore

A collection of purpose-built plugins that extend Jellyfin administration without external applications or dependencies.

| Plugin | Description |
| --- | --- |
| [Necto](https://github.com/siphonophore-org/necto) | Tools to keep your Jellyfin server reachable, secure and healthy. |
| [Zooid](https://github.com/siphonophore-org/zooid) | Keeps your whole collection of Jellyfin servers in sync with one another. |
| [Stolon](https://github.com/siphonophore-org/stolon) | Shared components and services for Siphonophore's Jellyfin plugins. |

## The name

A siphonophore is a colony of specialized members that live as one animal. Each member is a zooid, and every zooid grows from the stolon, the stem that joins them. The nectophores are the swimming bells that move the colony.
